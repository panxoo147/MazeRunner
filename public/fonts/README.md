# วางไฟล์ฟอนต์พิกเซลภาษาไทยตรงนี้

Google Fonts ไม่มีฟอนต์แนวพิกเซล/8-bit ตัวไหนที่รองรับภาษาไทยจริง ๆ (ฟอนต์พิกเซลทุกตัวรองรับแค่ละติน/ตัวเลข เพราะภาษาไทยมีสระ/วรรณยุกต์ซ้อนที่ระบบฟอนต์พิกเซลทำได้ยาก) ตอนนี้ตัวอักษรไทยทั้งแอปจึงใช้ **Chakra Petch** (ฟอนต์เหลี่ยม/แนวเทคโนที่ใกล้เคียงพิกเซลที่สุดที่หาได้) เป็นตัวสำรองไปก่อน

ถ้าคุณมีไฟล์ฟอนต์พิกเซลภาษาไทยของตัวเอง (เช่น ซื้อมา หรือมีสิทธิ์ใช้งานถูกต้อง) ให้วางไฟล์ไว้ในโฟลเดอร์นี้โดยตั้งชื่อว่า:

```
public/fonts/thai-pixel.woff2   (แนะนำ — ไฟล์เล็กสุด โหลดเร็วสุด)
public/fonts/thai-pixel.ttf     (หรือใช้ไฟล์นี้แทนก็ได้ถ้าไม่มี .woff2)
public/fonts/thai-pixel.otf     (หรือไฟล์นี้)
```

ไม่ต้องมีครบทุกไฟล์ — มีไฟล์เดียวก็พอ (เว็บจะลองโหลดตามลำดับ woff2 → ttf → otf ให้เอง ถ้าไฟล์ไหนไม่มีก็จะข้ามไปเงียบ ๆ ไม่มี error)

เมื่อวางไฟล์ตามชื่อด้านบนแล้ว **ไม่ต้องแก้โค้ดอะไรเพิ่ม** — `style.css` ตั้ง `@font-face` รอไว้แล้ว ตัวอักษรไทยทั้งแอป (ทุกปุ่ม ทุกหน้า) จะเปลี่ยนไปใช้ฟอนต์พิกเซลของคุณทันทีที่รีเฟรชหน้าเว็บ
