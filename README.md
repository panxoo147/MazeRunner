# Maze Race 🌀

เกม multiplayer เล่นผ่านเว็บ — สร้างหรือเข้าห้องด้วยโค้ด แล้วแข่งกันหาทางออกจากเขาวงกตให้เร็วที่สุด บังคับได้ทั้ง **เมาส์ / คีย์บอร์ด (WASD) / จอยสติ๊กบนมือถือ** เก็บไอเทมกล่องสุ่มระหว่างทางเพื่อเร่งตัวเองหรือกวนคู่แข่ง รองรับผู้เล่นได้สูงสุด **100 คนต่อห้อง** (โฮสต์ตั้งค่าจำนวนผู้เล่นสูงสุดและจำนวนคนเข้าเส้นชัยที่จะจบเกมได้เอง)

Repo: [github.com/panxoo147/MazeRunner](https://github.com/panxoo147/MazeRunner)

## วิธีรันบนเครื่องตัวเอง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
git clone https://github.com/panxoo147/MazeRunner.git
cd MazeRunner
npm install
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

เปิดหลาย ๆ แท็บ/เครื่อง เพื่อทดสอบว่าเป็น multiplayer จริง — คนแรกกด "Create Room" จะได้โค้ด 5 ตัว ส่งโค้ดนั้นให้เพื่อนกรอกที่ช่อง "Room Code" แล้วกด "Join Room" (UI ทั้งแอปเป็นภาษาอังกฤษ)

## วิธีเล่น

1. ใส่ชื่อ กดปุ่มเลือกตัวละคร (อิโมจิ) เพื่อเปิดหน้าต่างเลือกจากตัวเลือกกว่า 100 แบบ แล้วเลือกโหมดควบคุมที่ถนัด (🖱️ เมาส์ / ⌨️ WASD / 📱 จอยสติ๊กสำหรับมือถือ — สลับได้ระหว่างเล่นด้วยปุ่ม `M` หรือแตะปุ่มมุมจอ)
2. กด **Create Room** (จะได้เป็นโฮสต์ — ตั้งค่าจำนวนผู้เล่นสูงสุดของห้อง 2-100 คน และจำนวนคนที่ต้องเข้าเส้นชัยก่อนจบเกมได้เอง) หรือ **Join Room** ด้วยโค้ดที่ได้รับมา
3. รอผู้เล่นเข้าห้องให้ครบ แล้วโฮสต์กด **Start Race**
4. นับถอยหลัง 5 วินาที แล้วเริ่มแข่ง — หาทางออกไปให้ถึงวงกลมสีทองที่เขียนว่า **EXIT** ให้เร็วที่สุด
5. ระหว่างทางมีกล่องของขวัญ 🎁 (ไอเทมกล่องสุ่ม) กระจายอยู่ทั่วเขาวงกต เก็บแล้วจะได้ไอเทมแบบสุ่ม 1 ใน 3: ⚡ เร่งความเร็ว, 🌀 กวนใจคู่แข่ง (สลับทิศบังคับชั่วคราว), 🧭 เข็มทิศ (ชี้เส้นทางลัดไปทางออก) — กดใช้ด้วยปุ่มบนหน้าจอหรือ `Space`
6. ดูอันดับสดได้ที่มุมขวาบน และดูภาพรวมเขาวงกต + ตำแหน่งทุกคนได้จากมินิแมพมุมล่างขวา (จะซ่อนอัตโนมัติบนจอมือถือขนาดเล็กเพื่อไม่ให้บังจอ)
7. เมื่อผู้เล่นเข้าเส้นชัยครบตามจำนวนที่โฮสต์ตั้งไว้ (หรือหมดเวลา) จะเห็นหน้าผลการแข่งขันแบบโพเดียม 3 อันดับแรก โฮสต์กด **Race Again** เพื่อสุ่มเขาวงกตใหม่แล้วแข่งต่อได้

## ธีมและ UI

- โทนสีขาวดำพาสเทล (grayscale) ทั้งแอป ยกเว้นจุดที่มีความหมายเชิงเกมเพลย์ (จุดออก EXIT สีทอง, โซนเกิดสีเขียวมิ้นต์, สีเอฟเฟกต์ไอเทม, จุดตัวเองบนมินิแมพ) ที่ตั้งใจคงสีไว้ให้สังเกตง่าย
- UI ทั้งแอปเป็นภาษาอังกฤษล้วน ใช้ฟอนต์พิกเซล/8-bit ตัวเดียวทั่วทั้งแอป ทุกปุ่มทุกจุด: **[Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans)** จาก Google Fonts (มีน้ำหนักตัวอักษร 400-700 ให้ใช้ได้ทั้งข้อความปุ่ม/ตัวอักษรทั่วไปและจุดเด่นอย่างโลโก้ โค้ดห้อง นาฬิกาจับเวลา ตัวเลขนับถอยหลัง และอันดับบนโพเดียม)
- หน้าจอมือถือปรับ layout ให้เหมาะกับจอเล็ก/แนวนอน (ซ่อนมินิแมพอัตโนมัติเมื่อจอเล็ก, ย้ายนาฬิกาไปกลางบนจอ, ย่อขนาดกล่องไอเทม)

## เทคโนโลยีที่ใช้ และเหตุผล

- **Node.js + Express + Socket.IO** — เหมาะกับเกม real-time multiplayer, เขียนง่าย, community ใหญ่, รองรับ WebSocket fallback อัตโนมัติ
- **สร้างเขาวงกตฝั่ง server** (`maze.js`, อัลกอริทึม recursive backtracker + เจาะกำแพงเพิ่มแบบสุ่มกันตันคนแน่น) เพื่อให้ทุกคนในห้องเจอเขาวงกตเดียวกัน ขนาดเขาวงกตขยายตามจำนวนผู้เล่นในห้อง
- **การเคลื่อนที่/ชนกำแพงคำนวณฝั่ง client** เพื่อความลื่นไหลแบบ 60fps แม้มีคนเป็นร้อย ส่วน server แค่รีเลย์ตำแหน่งแบบ throttle (10 ครั้ง/วินาที) และตรวจสอบผลเข้าเส้นชัยแบบคร่าว ๆ กันโกง — เลือกออกแบบแบบนี้เพื่อไม่ให้ server ต้องแบกฟิสิกส์ของผู้เล่นทุกคนพร้อมกัน
- **ไอเทมกล่องสุ่ม** — จุดเก็บของบนแผนที่ไม่ผูกชนิดไอเทมไว้ล่วงหน้า ชนิดไอเทมจะถูกสุ่มฝั่ง server ตอนที่ผู้เล่นเก็บจริง ๆ เท่านั้น (กันไม่ให้ client ล่วงรู้หรือปรับแต่งผลลัพธ์)
- คีย์บอร์ดอ่านค่าด้วย `event.code` (ตำแหน่งปุ่มจริงบนคีย์บอร์ด) แทน `event.key` เพื่อให้ WASD ใช้งานได้แม้เปลี่ยน layout คีย์บอร์ดเป็นภาษาอื่น (เช่น ไทย)

## โครงสร้างไฟล์

```
maze-race/

├── maze.js         อัลกอริทึมสร้างเขาวงกต + จุดวางไอเทม
├── loadtest.js     สคริปต์จำลองผู้เล่นหลายคนเพื่อทดสอบโหลด (ดูหัวข้อด้านล่าง)
├── package.json
└── public/
    ├── index.html  หน้าเว็บ (home / lobby / game / results + modal ตั้งค่าห้อง/เลือกตัวละคร)

    └── game.js     เรนเดอร์ canvas, ควบคุมด้วยเมาส์/WASD/จอย, ชนกำแพง, ไอเทม, sync กับ server
```

## ทดสอบด้วยผู้เล่นจำลองหลายคน (load test)

ไม่ต้องหาเพื่อนจริงมาช่วยทดสอบก็ได้ — มีสคริปต์ `loadtest.js` ที่จำลองผู้เล่นจำนวนมากเข้าห้องเดียวกัน วิ่งหาทางออกเอง เก็บ/ใช้ไอเทมเอง แล้วสรุปผลให้ดูตอนจบ (อันดับ, เวลาเข้าเส้นชัย, จำนวนไอเทมที่เก็บได้, error ถ้ามี)

```bash
npm install          # ติดตั้ง socket.io-client ที่ loadtest.js ต้องใช้ (อยู่ใน devDependencies แล้ว)
npm run loadtest -- --players 45
```

ต้องรัน `npm start` (เปิดเซิร์ฟเวอร์) ไว้อีกหน้าต่างหนึ่งก่อน ตัวเลือกที่ปรับได้:

- `--players <n>` จำนวนผู้เล่นจำลอง (ค่าเริ่มต้น 20)
- `--url <url>` เซิร์ฟเวอร์ที่จะยิงเข้าไปทดสอบ (ค่าเริ่มต้น `http://localhost:3000` — ใส่ลิงก์ที่ deploy ไว้ก็ทดสอบเซิร์ฟเวอร์จริงได้เลย)
- `--code <code>` เข้าร่วมห้องที่มีอยู่แล้วแทนการสร้างห้องใหม่ (เผื่ออยากเทสเติมคนในห้องที่เปิดเบราว์เซอร์เล่นอยู่จริง — ต้องมีคนกดเริ่มแข่งเองในเบราว์เซอร์)
- `--speed <px/s>` ความเร็วเคลื่อนที่พื้นฐานของบอท (ค่าเริ่มต้น 170)

ดูตัวเลือกทั้งหมดได้ด้วย `node loadtest.js --help`

## Deploy ขึ้นออนไลน์ให้เพื่อนเล่นจริง

เกมนี้ต้องมี **server ที่รันตลอดเวลาและรองรับ WebSocket** (ต่างจากเว็บ static ทั่วไป) เพราะใช้ Socket.IO เชื่อมต่อสด ๆ ระหว่างผู้เล่น **อย่าใช้ GitHub Pages / Netlify / Vercel แบบ static** เพราะไม่มี Node.js server รันถาวรให้ Socket.IO ใช้งาน

### แนะนำ: Render.com (ฟรี ไม่ต้องผูกบัตรเครดิต)

1. ไปที่ [render.com](https://render.com) สมัครสมาชิก (ล็อกอินด้วย GitHub ได้เลย ไม่ต้องกรอกบัตรเครดิต)
2. กด **New > Web Service** แล้วเลือก repo [`panxoo147/MazeRunner`](https://github.com/panxoo147/MazeRunner) (ต้องเชื่อมบัญชี GitHub กับ Render ก่อนถึงจะเห็น repo ในลิสต์)
3. ตั้งค่า: **Environment = Node**, **Build Command = `npm install`**, **Start Command = `npm start`**, **Instance Type = Free** แล้วกด **Create Web Service**
4. รอ build/deploy ประมาณ 1-2 นาที จะได้ลิงก์แบบ `https://xxxx.onrender.com` — ส่งลิงก์นี้ให้เพื่อนเข้าได้เลย
5. เมื่อมีการแก้โค้ดใหม่ แค่ `git push` ขึ้น repo นี้ Render จะ deploy เวอร์ชันใหม่ให้อัตโนมัติ (auto-deploy)

**ข้อจำกัดของแผนฟรี:** ได้โควตา 750 ชั่วโมง instance ฟรีต่อเดือน และ server จะ **"หลับ" หลังไม่มีคนเข้าใช้ 15 นาที** พอมีคนเปิดลิงก์ครั้งแรกหลังจากหลับ จะต้องรอ **ตื่นประมาณ 1 นาที** — แนะนำให้เปิดลิงก์ทิ้งไว้ล่วงหน้าสัก 1 นาทีก่อนเริ่มแข่งกับเพื่อน

### ทางเลือกอื่น

- **Railway.app** — deploy จาก repo อัตโนมัติเหมือนกัน แต่ปัจจุบัน (2026) ให้เครดิตทดลองฟรี $5 ใช้ได้ 30 วันเท่านั้น หลังจากนั้นเหลือเครดิตฟรีแค่ $1/เดือน (ไม่พอสำหรับรันทิ้งไว้ตลอดเวลา) และต้องผูกบัตรเครดิตถ้าจะใช้เกินเครดิตฟรี เหมาะกับทดสอบระยะสั้นมากกว่า
- **Fly.io** — ปัจจุบันตัดแผนฟรีออกไปมากแล้ว ต้องผูกบัตรเครดิตและมีค่าใช้จ่ายตามการใช้งานจริง เหมาะถ้าต้องการความเสถียรและไม่ downtime แบบ Render free tier

(ข้อมูลราคา/เงื่อนไข ณ ปี 2026 อาจเปลี่ยนแปลงได้ ควรเช็กหน้าราคาล่าสุดของแต่ละเจ้าอีกครั้งก่อน deploy จริง)

## ปรับแต่งเพิ่มเติม

- จำนวนผู้เล่นสูงสุดต่อห้อง (ค่าเริ่มต้น/ขั้นต่ำ/เพดานที่โฮสต์ตั้งได้): แก้ `DEFAULT_MAX_PLAYERS`, `MIN_MAX_PLAYERS`, `HARD_MAX_PLAYERS` ใน `server.js`
- จำนวนคนเข้าเส้นชัยที่ใช้จบเกม (ค่าเริ่มต้น/ขั้นต่ำ): แก้ `DEFAULT_FINISH_LIMIT`, `MIN_FINISH_LIMIT` ใน `server.js`
- ขนาดเขาวงกต / ความหนาแน่นทางลัด: แก้ `sizeForPlayers()` และ `braidChance` ใน `maze.js`
- ความเร็วผู้เล่น / ระยะเมาส์ที่ทำให้วิ่งเต็มสปีด: แก้ `MAX_SPEED`, `DEADZONE`, `MAX_REACH` ใน `public/game.js`
- ชนิด/จำนวนไอเทม และเวลารีสปอน: แก้ `ITEM_TYPES` ใน `maze.js` และ `ITEM_RESPAWN_MS` ใน `server.js`
- สีธีม/ฟอนต์: แก้ตัวแปร CSS ใน `:root` ของ `public/style.css` (`--bg`, `--panel`, `--accent`, `--font-display` ฯลฯ) และแก้ลิงก์ Google Fonts ใน `public/index.html` ถ้าอยากเปลี่ยนฟอนต์พิกเซล
