# Maze Race 🌀

เกม multiplayer เล่นผ่านเว็บ — สร้างหรือเข้าห้องด้วยโค้ด แล้วแข่งกันบังคับจุดด้วย **เคอร์เซอร์เมาส์** ให้ออกจากเขาวงกตให้เร็วที่สุด รองรับผู้เล่นได้ถึง **50 คนต่อห้อง**

## วิธีรันบนเครื่องตัวเอง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

เปิดหลาย ๆ แท็บ/เครื่อง เพื่อทดสอบว่าเป็น multiplayer จริง — คนแรกกด "สร้างห้องใหม่" จะได้โค้ด 5 ตัว ส่งโค้ดนั้นให้เพื่อนกรอกที่ช่อง "เข้าร่วมห้อง"

## วิธีเล่น

1. ใส่ชื่อ แล้วกด **สร้างห้องใหม่** (จะได้เป็นโฮสต์) หรือ **เข้าร่วมห้อง** ด้วยโค้ดที่ได้รับมา
2. รอผู้เล่นเข้าห้องให้ครบ แล้วโฮสต์กด **เริ่มการแข่งขัน**
3. นับถอยหลัง 5 วินาที แล้วเริ่มแข่ง — ขยับเมาส์ไปทางไหน ตัวละครจะวิ่งตามทิศนั้น (ยิ่งเมาส์ห่างจากตัวละครมาก ยิ่งวิ่งเร็ว)
4. หาทางออกไปให้ถึงวงกลมสีทองที่เขียนว่า **EXIT** ให้เร็วที่สุด
5. ดูอันดับสดได้ที่มุมขวาบน และดูภาพรวมเขาวงกต + ตำแหน่งทุกคนได้จากมินิแมพมุมล่างขวา
6. เมื่อทุกคนเข้าเส้นชัย (หรือหมดเวลา) จะเห็นหน้าผลการแข่งขัน โฮสต์กด **แข่งใหม่อีกครั้ง** เพื่อสุ่มเขาวงกตใหม่แล้วแข่งต่อได้

## เทคโนโลยีที่ใช้ และเหตุผล

- **Node.js + Express + Socket.IO** — เหมาะกับเกม real-time multiplayer, เขียนง่าย, community ใหญ่, รองรับ WebSocket fallback อัตโนมัติ
- **สร้างเขาวงกตฝั่ง server** (`maze.js`, อัลกอริทึม recursive backtracker + เจาะกำแพงเพิ่มแบบสุ่มกันตันคนแน่น) เพื่อให้ทุกคนในห้องเจอเขาวงกตเดียวกัน
- **การเคลื่อนที่/ชนกำแพงคำนวณฝั่ง client** เพื่อความลื่นไหลแบบ 60fps แม้มีคน 40-50 คน ส่วน server แค่รีเลย์ตำแหน่งแบบ throttle (10 ครั้ง/วินาที) และตรวจสอบผลเข้าเส้นชัยแบบคร่าว ๆ กันโกง — เลือกออกแบบแบบนี้เพื่อไม่ให้ server ต้องแบกฟิสิกส์ของผู้เล่นทุกคนพร้อมกัน

## โครงสร้างไฟล์

```
maze-race/
├── server.js       ระบบ lobby, Socket.IO events, จับเวลา/อันดับ
├── maze.js         อัลกอริทึมสร้างเขาวงกต
├── package.json
└── public/
    ├── index.html  หน้าเว็บ (home / lobby / game / results)
    ├── style.css
    └── game.js     เรนเดอร์ canvas, ควบคุมด้วยเมาส์, ชนกำแพง, sync กับ server
```

## Deploy ขึ้นออนไลน์ให้เพื่อนเล่นจริง

เกมนี้ต้องมี **server ที่รันตลอดเวลาและรองรับ WebSocket** (ต่างจากเว็บ static ทั่วไป) เพราะใช้ Socket.IO เชื่อมต่อสด ๆ ระหว่างผู้เล่น **อย่าใช้ GitHub Pages / Netlify / Vercel แบบ static** เพราะไม่มี Node.js server รันถาวรให้ Socket.IO ใช้งาน

### แนะนำ: Render.com (ฟรี ไม่ต้องผูกบัตรเครดิต)

1. สร้างบัญชี [GitHub](https://github.com) ถ้ายังไม่มี แล้วสร้าง repository ใหม่ (public หรือ private ก็ได้) เช่นชื่อ `maze-race`
2. ในหน้า repo ที่เพิ่งสร้าง กด **"uploading an existing file"** แล้วลากทั้งโฟลเดอร์โปรเจกต์ (ทุกไฟล์ยกเว้น `node_modules`) เข้าไป แล้วกด Commit — ไม่ต้องติดตั้งหรือใช้คำสั่ง `git` เลยก็ได้ถ้าไม่ถนัด (แต่ถ้าถนัด `git` ก็ `git init && git add . && git commit -m "init" && git push` ได้ตามปกติ)
3. ไปที่ [render.com](https://render.com) สมัครสมาชิก (ล็อกอินด้วย GitHub ได้เลย ไม่ต้องกรอกบัตรเครดิต)
4. กด **New > Web Service** แล้วเลือก repo `maze-race` ที่เพิ่งอัปโหลด
5. ตั้งค่า: **Environment = Node**, **Build Command = `npm install`**, **Start Command = `npm start`**, **Instance Type = Free** แล้วกด **Create Web Service**
6. รอ build/deploy ประมาณ 1-2 นาที จะได้ลิงก์แบบ `https://maze-race-xxxx.onrender.com` — ส่งลิงก์นี้ให้เพื่อนเข้าได้เลย

**ข้อจำกัดของแผนฟรี:** ได้โควตา 750 ชั่วโมง instance ฟรีต่อเดือน และ server จะ **"หลับ" หลังไม่มีคนเข้าใช้ 15 นาที** พอมีคนเปิดลิงก์ครั้งแรกหลังจากหลับ จะต้องรอ **ตื่นประมาณ 1 นาที** — แนะนำให้เปิดลิงก์ทิ้งไว้ล่วงหน้าสัก 1 นาทีก่อนเริ่มแข่งกับเพื่อน

### ทางเลือกอื่น

- **Railway.app** — deploy จาก repo อัตโนมัติเหมือนกัน แต่ปัจจุบัน (2026) ให้เครดิตทดลองฟรี $5 ใช้ได้ 30 วันเท่านั้น หลังจากนั้นเหลือเครดิตฟรีแค่ $1/เดือน (ไม่พอสำหรับรันทิ้งไว้ตลอดเวลา) และต้องผูกบัตรเครดิตถ้าจะใช้เกินเครดิตฟรี เหมาะกับทดสอบระยะสั้นมากกว่า
- **Fly.io** — ปัจจุบันตัดแผนฟรีออกไปมากแล้ว ต้องผูกบัตรเครดิตและมีค่าใช้จ่ายตามการใช้งานจริง เหมาะถ้าต้องการความเสถียรและไม่ downtime แบบ Render free tier

(ข้อมูลราคา/เงื่อนไข ณ ปี 2026 อาจเปลี่ยนแปลงได้ ควรเช็กหน้าราคาล่าสุดของแต่ละเจ้าอีกครั้งก่อน deploy จริง)

## ปรับแต่งเพิ่มเติม

- จำนวนผู้เล่นสูงสุดต่อห้อง: แก้ `MAX_PLAYERS_PER_LOBBY` ใน `server.js`
- ขนาดเขาวงกต / ความหนาแน่นทางลัด: แก้ `sizeForPlayers()` และ `braidChance` ใน `maze.js`
- ความเร็วผู้เล่น / ระยะเมาส์ที่ทำให้วิ่งเต็มสปีด: แก้ `MAX_SPEED`, `DEADZONE`, `MAX_REACH` ใน `public/game.js`
